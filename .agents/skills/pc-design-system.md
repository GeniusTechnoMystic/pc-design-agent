# PC Design System Skill

## Trigger

Use when working on component ingestion, compatibility logic, recommendation ranking, benchmark integration, Linux support analysis, firmware openness analysis, or NZ/AU pricing workflows.

## Checklist

- Identify the entity classes involved.
- Confirm the authoritative source set.
- Preserve source URLs and timestamps.
- Distinguish hard constraints from soft heuristics.
- Normalize costs and benchmarks before comparing.
- Surface Linux, firmware, lifecycle, and repairability notes.
- Record missing data and confidence gaps.

## Output expectations

- Structured facts
- Compatibility verdicts
- Ranked options with trade-offs
- Evidence-backed caveats
