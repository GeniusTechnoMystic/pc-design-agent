# Core Rules

- Never treat a benchmark, support claim, or compatibility statement as canonical without a source URL.
- Prefer official specs for hard physical and electrical characteristics.
- Prefer field evidence for Linux operability and firmware update reality.
- Separate hard compatibility failures from soft design warnings.
- Preserve conflicting facts when confidence is insufficient to collapse them.
- Normalize all costs to landed NZD where practical.
- Record retrieval timestamps for prices, listings, benchmarks, and support records.
- Mark every recommendation with confidence, caveats, and evidence links.
